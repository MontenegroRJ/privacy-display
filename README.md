# Privacy Display (Android)

Overlay de listras sobre a tela inteira, com intensidade e tamanho ajustáveis.

## Gerar o APK (sem computador)
1. Suba esta pasta para um repositório seu no GitHub (branch `main`).
2. Aba **Actions** > **Build APK** > **Run workflow** (ou só dê push).
3. Ao terminar, baixe o artefato `privacy-display-apk` e instale o `app-debug.apk`.

## Gerar o APK (Android Studio)
Abra a pasta, deixe sincronizar e rode **Build > Build APK(s)**.

## Uso
Abra o app, ative a chave e conceda "Sobrepor a outros apps".
